GitHub Editor - Help

About

A web-based Markdown editor that syncs with your GitHub repository. Edit notes directly in your browser with automatic saving to GitHub.

Keyboard Shortcuts

Ctrl/Cmd + S Save current file to GitHub
Ctrl/Cmd + D Open today's daily note
Ctrl/Cmd + B Toggle sidebar visibility
Ctrl/Cmd + K Toggle AI chat panel
Ctrl/Cmd + , Open settings
Ctrl/Cmd + / Show this help

Features

  • File Tree: Browse and switch between files in your repository
  • Auto-save: Changes are automatically saved locally and synced to GitHub every 15 minutes
  • Daily Notes: Create and manage daily notes with customizable folder and date format
  • AI Chat: Ask questions about your notes using Google's Gemini AI (requires API key)
  • Markdown Editor: Full-featured CodeMirror editor with syntax highlighting

Getting Started

  1. Click the settings (⚙️) button to configure your GitHub repository and access token
  2. Optionally add a Gemini API key to enable AI chat features
  3. Select files from the sidebar or click "Daily Note" to start editing
  4. Your changes are saved locally automatically and synced to GitHub periodically

Tips

  • All data is stored locally in your browser - your tokens never leave your device
  • Changes are indicated with a dot (●) in the window title
  • Use Ctrl/Cmd + S to manually save to GitHub anytime
  • The sidebar shows files with unsaved changes marked with a dot
